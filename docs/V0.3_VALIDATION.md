## Build-environment note

The archive intentionally excludes `node_modules`. The packaging environment could not access the npm registry, so the conventional dependency install and Vite production build were not repeated locally. The included GitHub Actions workflow performs that install/build in the deployment environment, and the source was validated independently before archiving.
