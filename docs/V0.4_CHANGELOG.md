# NHL Coaching Insights — v0.4 change log

## Player identity and portraits

- Added a sweater-number-to-headshot map for all 19 Carolina players represented in the application.
- Replaced generic face-index use in Dashboard, Expanded Views, Featured Insights, Player Insights, Video, Head-to-Head Faceoffs, and Power Play widgets.
- Applied contained, bottom-aligned portrait rendering so the full head and shoulders remain visible.
- Added a specific safe crop for Nikolaj Ehlers in Player Insights and Video cards.

## Calendar

- Rebuilt the Calendar as the approved three-day schedule with a time gutter, event columns, contextual day headings, and a right-side agenda.
- Added June 2026 mini-month markers, Home/Away legend, selected day, scrollable agenda, and Add Task behavior.
- Reused the same agenda component inside the top-right Calendar drawer so both calendar entry points remain visually and functionally consistent.

## Dashboard customization

- Added 560 ms long-press detection on unused Dashboard workspace.
- Added persistent edit mode with Apple-style approved-blue minus controls and no shaking. The controls use `#4186FF` in dark mode, `#2155FC` in light mode, and `#0925AB` for hover/pressed states—only colors from the approved palette.
- Added an approved **Add Widgets** toolbar.
- Added a scrollable catalog with a persistent workspace-return strip.
- Added size selection, valid placement zones, placement previews, removal, reset-layout, Done, and tap-free-space exit.
- Added Game Flow, Penalty Watch, Line Matchups, Shot Quality, and Rest Risk widgets with populated compact/medium/large presentations.
- Persisted layout in browser local storage.

## Player and video rails

- Player Insights and Video roster cards now occupy one horizontally swipeable row.
- Hidden all visual scrollbars while preserving touch and trackpad navigation.
- Added player-based clip filtering and clip counts in Video.

## Stats and themes

- Replaced the blue selected-report strip with the approved inverse neutral selection.
- Completed light-mode surfaces for widgets, charts, side panels, Calendar, catalog, player cards, onboarding controls, and the slide-out menu.
- Selecting Light in onboarding now changes the onboarding overlay and modal immediately.

## Demo controls

- Retained icon-only reset.
- Removed the worded Restart control.
- Added **back 10 sec**, clamped to the start of the game and recomputed from the destination timestamp.

## Approved edit-control palette

- Replaced the Apple-red remove treatment with approved interface blues: `#4186FF` in dark mode and `#2155FC` in light mode.
- Kept a white minus glyph and theme-matched outer ring for immediate contrast without introducing colors outside the Figma palette.
