# NHL Coaching Insights — v0.3 change log

## Supplied Figma icon system

- Added all 49 supplied PNG icons to a dedicated packaged icon library.
- Added `HdIcon.tsx`, which uses each PNG as a CSS mask so the exact supplied geometry inherits dark/light theme colors.
- Replaced generic interface symbols throughout primary navigation, Dashboard, AI Insights, Featured Insights, Player Insights, Video, Stats, Notes, Calendar, Preferences, onboarding, expansion controls, and side panels where a matching supplied icon exists.
- Kept specialized system chevrons or the restart glyph only where the supplied set has no semantically correct equivalent.

## Menu and typography

- Rebuilt the slide-out navigation proportions to remove the oversized font treatment.
- Menu width now scales between 250 and 300 px, icons are 29 px, rows are 52–58 px, and labels use the same 18/20 hierarchy as the Figma interface.
- Added centralized SF Pro system typography tokens:
  - Body: 18 pt target
  - Header: 20 pt target
  - Title: 24 pt target
  - Dense captions/tables: controlled 12–16 pt range
- Applied SF Pro Display weights to titles and headers and SF Pro Text/system UI weights to body copy and controls.
- Retained static time counters and disabled menu/counter motion.

## Figma surface and theme polish

- Preserved the approved 20 px screen margin, 20 px composition gaps, 12 px widget padding, 20 px corner radius, no decorative widget stroke, and no drop shadow.
- Dark palette remains based on `#02060F`, `#040814`, `#121723`, and `#1C212C`.
- Light palette uses `#E9EFF6`, `#E3EBF4`, `#F1F5F9`, `#F9FBFD`, `#FFFFFF`, and `#02060F`.
- Supplied icons inherit the correct foreground color in both themes without separate duplicated assets.
- Added target tuning for the 1194 × 834 11-inch iPad landscape viewport and the 1366 × 1024 review canvas.

## Deployment readiness

- The application now renders at the site root instead of opening the component gallery.
- Added base-path-aware image, video, and icon helpers; removed legacy internal preview asset paths.
- Added safe defaults for Vite `PORT` and `BASE_PATH`.
- Added `pnpm build:frontend` and a post-build `404.html` SPA fallback.
- Added a GitHub Pages workflow that derives the project base path automatically.
- Updated package versions, metadata, title, descriptions, README, deployment documentation, and validation.

## Preserved v0.2 functionality

- AI Insights compact/expanded/full-screen related views.
- Dark and light themes with identical geometry.
- Adaptive Player Insights widget packing and visibility controls.
- Featured Insights and Stats expansion reflow.
- Game 4 timeline controls, 17 clips, and timestamp-aware data.
- PostgreSQL migration, seed, API routes, and static fallback.
