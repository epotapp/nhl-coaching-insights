# NHL Coaching Insights — v0.2 change log

## Dashboard and AI Insights

- AI Insights now has a compact rail state, a large right-side expanded composition, and related stat/video miniatures.
- Related miniatures open dedicated full-screen views and return to the expanded AI insight.
- Compact right-rail widgets show only the highest-priority value and context.
- Dashboard spacing, type hierarchy, surfaces, and neutral dividers follow the approved iPad Figma guides.
- Dark and light themes share the same layout and use the approved neutral palettes.

## Player Insights

- Rebuilt around adaptive rows that redistribute every remaining widget after expand, collapse, hide, or show.
- Added compact, medium, wide, and expanded content variants.
- Every widget now fills its area with purpose-specific information: rankings, splits, comparisons, timelines, player context, and official Game 4 totals.
- Players who did not take a faceoff receive role/team-context information rather than an empty faceoff card.
- Visibility controls preserve at least one widget and repack all visible cards across the complete width.

## Featured Insights and Stats

- Featured composition retains the approved video, faceoff, shooting-sector, lineup, and lower insight structure.
- Head-to-Head Faceoffs and Shooting by Sector use the supplied approved visual compositions.
- Matplotlib assets include matching dark and light versions.
- Stats expansion uses full-width rows and moves paired widgets below without unused half-columns.

## Data and PostgreSQL readiness

- Added a normalized PostgreSQL/Drizzle schema for teams, players, games, events, shifts, team/player stats, videos, coaching insights, and widget preferences.
- Added lazy database initialization so the UI and health endpoint do not crash when PostgreSQL is offline.
- Added timestamp-aware dashboard, event, player, video, and widget-preference API endpoints.
- Added Docker Compose, migration, official Game 4 seed, frontend API client, and setup instructions.
- Bundled seed: Carolina Hurricanes 5–3 Vegas Golden Knights, 2026 Stanley Cup Final Game 4, game id `2025030414`.

## Validation

- Counter and time-value animations are disabled.
- No decorative widget strokes or drop shadows are introduced.
- TypeScript/TSX syntax, CSS structure, referenced assets, SQL seed generation, and ZIP integrity are checked during packaging.
