# v0.5 validation

Validation targets:

- TypeScript strict typecheck for the Vite frontend.
- Production Vite build with GitHub Pages fallback output.
- `scripts/validate-v0.5.mjs` source, import, CSS, asset, version, and required-file checks.
- Backend health plus Game 4 simulation/widget endpoint checks.
- Browser review in dark and light themes at the iPad landscape target.
- Interaction review for onboarding-to-Dashboard widget selection and the Dashboard widget catalog.

## Automated results

- Strict TypeScript typecheck: passed.
- `scripts/validate-v0.5.mjs`: passed with 106 TypeScript files, 14 CSS files, 131 assets, 49/49 declared icons, 17 videos, no syntax/import/CSS/placeholder/path failures.
- Vite 7.3.6 production build: passed; 1,709 modules transformed, hashed CSS/JS emitted, and `dist/404.html` generated for GitHub Pages routing.
- Backend Game 4 endpoints: connected and returning synchronized replay/widget payloads for game `2025030414`.

The Vite build reports informational chunk-placement notices for components that are both statically and dynamically imported. They do not block or invalidate the production bundle.

## Browser acceptance

Reviewed in the in-app browser at 1194 x 834 (iPad landscape class):

- Light dashboard and expanded Shots on Goal view render with light table/card surfaces and readable foreground contrast. Computed expanded-list and row backgrounds are `rgb(241, 245, 249)` with `rgb(2, 6, 15)` text.
- Backend status resolves to `Live API`; final Game 4 score, TOI/rest, faceoffs, shots, special teams, goaltending, shot-sector, workload, lineup, and insight data render from the API.
- Selecting `SV%`, `xG`, and `GVA` in onboarding produces Goaltending, Shooting by Sector, and Giveaways widgets in the dashboard layout, in priority order. The layout and focus labels survive a full navigation reload.
- Demo playback advances to period/clock state from the backend. Sector rows remain empty until tracked shots exist, goalie statistics follow the replay cursor, and possession/event widgets update over time.
- Personalized dashboard reviewed in dark mode; no browser warning or error entries were recorded.
- Dashboard edit-mode remove controls stay fully visible at widget edges; each uses a 21 px blue circle with a geometrically centered 8 x 2 px white minus while retaining a 32 px interaction target.

## Deployment boundary

The generated Pages output is ready. A live GitHub Pages deployment still requires the repository Actions variable `VITE_NHL_API_BASE_URL` to point to a publicly reachable HTTPS backend; Pages itself cannot host FastAPI.
