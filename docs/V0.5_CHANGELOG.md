# v0.5 changelog

## Data connection

- Added a typed FastAPI client for Game 4 simulation and widget frames.
- Kept the bundled game simulator as a deliberate resilience fallback.
- Added a visible data-source state to the score band.
- Updated GitHub Pages Actions configuration to accept `VITE_NHL_API_BASE_URL`.

## Dashboard widgets

- Existing widgets now prefer backend values for score, clock, strength, TOI/rest, faceoffs, shots, compact team stats, power play, and expanded stat summaries.
- New backend-driven widgets: Goaltending, Shooting by Sector, Head-to-Head Faceoffs, Shot Attempts, Giveaways, Video Moments, Game Pulse, Lineup Analyzer, and Shift Workload.
- Existing Game Flow, Penalty Watch, Line Matchups, Shot Quality, and Rest Risk views now use the backend widget payload when connected.
- Replay playback keeps sector and goaltending values aligned to the active game cursor instead of leaking final-game fallback values.

## Personalization

- Onboarding explains that selected stats become Dashboard widgets.
- Completing onboarding converts the ordered selection into a valid zone/size layout.
- The resulting layout and ordered focus labels are persisted separately from v0.4.

## Visual system

- Added final-cascade light-theme coverage for expanded stat tables, summary cards, video rows, pagination, native video, and all new widgets.
- Reused the supplied Figma icon masks, neutral palette, compact typography, rounded panels, and iPad-first density.
